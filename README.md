# DREM PLAY ― 夢芝居 × StoryVerse（統合サイト）

静的サイトです。ファイル構成：

- `index.html` … トップ
- `works.html` … 作品（夢芝居）
- `tools.html` … ツール群（StoryVerse）
- `style.css` … デザイン共通
- `assets/` … 画像（ロゴ）

## 更新のしかた
ファイルを編集して、このリポジトリにアップロード（上書き）すれば、Cloudflare Pages が自動で公開し直します。

## 仮の部分
- 作品ページの Amazon ボタン：作品ごとの Kindle URL に差し替え予定
- ツールのダウンロードボタン：公開時に実ファイルへ接続予定
- 作品カードの絵：表紙・キービジュアルに差し替え予定
